# Incident Workflow

## 1. Establish scope

Identify the affected host, service, users, start time, and whether the problem is intermittent or continuous.

## 2. Preserve evidence

Capture relevant logs, service status, resource usage, and recent changes before destructive actions.

## 3. Isolate

Separate infrastructure, network, runtime, application, and dependency hypotheses.

## 4. Test

Run one controlled test at a time and record the result.

## 5. Recover

Prefer the smallest reversible action that restores service.

## 6. Verify and document

Confirm service health from the user's perspective, then document cause, evidence, fix, and prevention.
